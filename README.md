# Трекер зарплаты менеджера по продажам курсов

Сайт для учёта оплат клиентов онлайн-школы и автоматического расчёта зарплаты: аванс (1–15 числа), остаток (16-го и до конца месяца) и итог за месяц. Данные лежат в базе Supabase (Postgres), поэтому сайт на GitHub Pages открывается с телефона и компьютера и показывает одно и то же.

## Возможности

- Вход по почте и паролю, данные каждого пользователя защищены правилами RLS.
- Ввод фамилии, суммы оплаты, даты и типа клиента (новый / продление).
- Список клиентов за месяц с поиском, редактированием (ФИО, сумма, дата, тип) и удалением.
- Расчёт: 10% с нового клиента, 2,5% с продления (проценты меняются в настройках).
- Оклад вводится вручную и сохраняется. По умолчанию половина оклада идёт в аванс.
- KPI: план по новым, план по продлениям и один общий бонус. Бонус платится, когда выполнены все планы, и входит в остаток зарплаты.
- До плана показывается, сколько не хватает в рублях, и сколько в сумме не хватает до бонуса.
- Месячная выгрузка в CSV (открывается в Excel).

## Как считается зарплата

- Аванс = часть оклада + проценты с оплат с 1 по 15 число.
- Остаток = остаток оклада + проценты с оплат с 16 числа до конца месяца + бонус KPI.
- Итого = аванс + остаток.

## Настройка за 10 минут

1. Создайте бесплатный проект на supabase.com.
2. Откройте SQL Editor, вставьте содержимое `supabase/schema.sql` и нажмите Run. Появятся таблицы `clients` и `settings` с защитой RLS.
3. В Project Settings → API скопируйте Project URL и `anon public` key и вставьте их в `js/config.js`. Ключ `service_role` в репозиторий не добавляйте.
4. Откройте сайт, нажмите «Создать аккаунт» и зарегистрируйтесь.
5. Когда зарегистрируетесь, отключите новые регистрации: Authentication → Sign In / Providers → выключите Allow new users to sign up. Тогда зайти сможете только вы.
6. Если Supabase просит подтвердить почту, перейдите по ссылке из письма. Для личного пользования подтверждение можно отключить в настройках Email-провайдера.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите все файлы проекта.
2. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://ваш-ник.github.io/название-репозитория/`.
4. В Supabase: Authentication → URL Configuration → Site URL укажите этот адрес.
5. На телефоне откройте ссылку и добавьте её на главный экран.
